# 副脚本通信规范

## 1. 句柄文件

受 GL 管理的子脚本启动后，在自己的脚本目录创建：

```text
A_ScriptName.txt
```

当前入口统一为：

```text
MAIN.ahk
```

因此实际文件为：

```text
MAIN.ahk.txt
```

文件内容只有当前 GUI 的真实 hwnd。

## 2. GL 读取方式

GL 根据当前脚本的 `MAIN.ahk` 路径确定：

```text
MAIN.ahk
↓
MAIN.ahk.txt
↓
读取 hwnd
```

GL 不通过固定窗口类名查找子脚本。

## 3. 退出消息

统一消息：

```text
0xB001
```

退出原因：

```text
wParam = 1 → GL 切换脚本
wParam = 2 → GL 管理器 F8 退出
```

子脚本注册消息处理：

```ahk
OnMessage(0xB001, ...)
```

## 4. GL 切换

切换脚本时：

```text
GL 读取当前 hwnd
↓
PostMessage(0xB001, 1, 0)
↓
子脚本收到消息
↓
子脚本执行自己的 Stop/清理
↓
删除 MAIN.ahk.txt
↓
ExitApp
↓
GL 等待句柄文件消失
↓
GL 启动目标 MAIN.ahk
```

GL 不直接释放子脚本的按键，也不依赖子脚本具体按键种类。

## 5. GL F8

F8 退出管理器时：

```text
GL 向当前子脚本发送：
0xB001, wParam=2
↓
子脚本执行退出清理
↓
GL 记录退出日志
↓
GL 自身 ExitApp
```

GL F8 不等待子脚本退出完成。

## 6. 子脚本要求

会保持按键或运行 Timer 的子脚本必须：

- 在退出路径停止 Timer。
- 释放自身保持的按键。
- 删除自己的 hwnd 文件。
- 注册 OnExit 做最终资源清理。

具体的 Stop 逻辑属于子脚本自己的 Process / Action，通信协议不规定具体按键。
