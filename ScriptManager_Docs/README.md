# ScriptManager 文档

## 权威规范

```text
ahk/AHK项目规范.md
```

## 公共库函数

公共库的具体函数说明统一放在：

```text

```

源码函数只保留一条“函数作用 + 参数”注释，详细解释集中在该文档中。
