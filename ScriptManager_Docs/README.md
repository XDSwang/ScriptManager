# ScriptManager 公共库文档

## 项目定位

ScriptManager 管理独立运行的 AHK 副脚本。

核心：

- 管理器通过路径启动副脚本。
- 副脚本生成自己的 hwnd 文件并保存窗口句柄。
- 管理器读取句柄并发送消息控制。
- 公共库只提供能力，不保存跨脚本业务状态。
- 项目的变量作用域、函数职责、命名和模块架构统一以 `ahk/AHK项目规范.md` 为准。

## 文档说明

- `ahk/AHK项目规范.md`：唯一权威项目规范。
- `副脚本通信规范.md`：副脚本与 GL 管理器之间的具体通信协议。
- 其他历史性的架构、命名、公共库设计规范已删除，避免出现多套规则。
