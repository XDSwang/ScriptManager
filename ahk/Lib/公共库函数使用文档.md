# 公共库函数使用文档

本文件是 ahk/Lib 公共库的详细使用说明。

公共库源码只保留“函数作用 + 参数”简短注释。完整用途、返回值、调用方式和示例统一记录在本文件。

---

## 一、当前标准公共库

当前业务脚本主要使用：

- Lib/Common：跨脚本公共能力。
- Lib/Action：公共动作函数。

### 1. Common/Config.ahk

配置类：GLConfig

| 配置 | 当前值 | 用途 |
|---|---:|---|
| GuiWidth | 300 | GUI宽度 |
| GuiHeight | 35 | GUI高度 |
| GuiAlpha | 220 | GUI透明度 |
| ExitMessage | 0xB001 | GL退出消息编号 |

说明：当前 GLGui.Create() 内部仍直接使用默认参数和透明度 220；GLConfig 保存项目统一配置值。

### 2. Common/GUI.ahk

#### GLGui.Create

作用：创建项目统一样式的 GUI。

参数：

- title：窗口标题，默认空字符串。
- width：窗口宽度，默认 300。
- height：窗口高度，默认 35。

返回：创建完成的 AHK GUI 对象。

当前行为：

- AlwaysOnTop
- 黑色背景
- Microsoft YaHei
- s9
- 白色默认字体
- 透明度 220

示例：

~~~ahk
myGui := GLGui.Create("Shift 控制")
~~~

#### GLGui.UpdateList

作用：更新 GL 管理器脚本名称列表，并把当前脚本显示为红色，其余脚本显示为白色。

参数：

- gui：GLGui.Create() 返回的 GUI 对象。
- scripts：脚本完整路径数组。
- currentIndex：当前脚本在数组中的索引。

返回：成功时返回 GUI 对象；GUI 无效时返回 0。

scripts 示例：

~~~ahk
scripts := [
    "E:\Project\Business\SHIFT\MAIN.ahk",
    "E:\Project\Business\WQFFF\MAIN.ahk"
]
GLGui.UpdateList(glGui, scripts, 1)
~~~

函数内部通过路径提取文件名用于显示。

### 3. Common/Logger.ahk

#### GLLogger.Info

作用：向 AutoHotkey 调试输出写入一条带 [AHK] 前缀的信息。

参数：

- msg：要输出的消息文本。

返回：无显式返回值。

示例：

~~~ahk
GLLogger.Info("脚本启动")
~~~

---

### 4. Common/Message.ahk

#### SendExitMessage

作用：向指定窗口发送项目统一的 GL 退出消息。

参数：

- hwnd：目标窗口句柄。

消息编号：

~~~text
0xB001
~~~

返回：无显式返回值。

示例：

~~~ahk
SendExitMessage(hwnd)
~~~

子脚本端注册：

~~~ahk
OnMessage(0xB001, GL_Exit)
~~~

### 6. Action/Keyboard.ahk

#### KeyDown

作用：按下指定按键。

参数：

- key：AHK 按键名称，例如 "w"、"q"、"LShift"。

返回：无显式返回值。

示例：

~~~ahk
KeyDown("w")
~~~

#### KeyUp

作用：释放指定按键。

参数：

- key：AHK 按键名称。

返回：无显式返回值。

示例：

~~~ahk
KeyUp("w")
~~~

### 7. Action/Timer.ahk

#### Timer_Start

作用：启动或重新设置指定回调函数的定时器。

参数：

- callback：定时器调用的函数或函数对象。
- interval：执行间隔，单位为毫秒。

返回：无显式返回值。

示例：

~~~ahk
Timer_Start(PressF, 100)
~~~

#### Timer_Stop

作用：停止指定回调函数对应的定时器。

参数：

- callback：需要停止的函数或函数对象。

返回：无显式返回值。

示例：

~~~ahk
Timer_Stop(PressF)
~~~

---

### 8. Action/Window.ahk

#### GL_WindowActivate

作用：通过 hwnd 激活指定窗口。

参数：

- hwnd：目标窗口句柄。

返回：无显式返回值。

示例：

~~~ahk
GL_WindowActivate(hwnd)
~~~

#### GL_WindowExists

作用：检查指定 hwnd 对应的窗口是否存在。

参数：

- hwnd：目标窗口句柄。

返回：

- 窗口存在：返回窗口句柄。
- 不存在或 hwnd 无效：返回 0。

示例：

~~~ahk
if GL_WindowExists(hwnd)
    MsgBox("窗口存在")
~~~

## 二、模板/扩展公共库

以下库位于 ahk/Lib，主要用于公共模板或扩展场景；使用时需要显式 Include。

### 9. File/FileControl.ahk

#### File_Exists

作用：检查指定文件是否存在。

参数：

- path：文件路径。

返回：存在时返回 FileExist() 的结果，不存在时返回空值。

示例：

~~~ahk
if File_Exists("test.txt")
    MsgBox("文件存在")
~~~

#### File_Read

作用：读取文本文件内容。

参数：

- path：文件路径。

返回：FileRead() 读取到的文件内容。

示例：

~~~ahk
text := File_Read("config.txt")
~~~

#### File_Write

作用：向指定文件追加写入文本数据。

参数：

- path：文件路径。
- data：要写入的内容。

返回：固定返回 true。

示例：

~~~ahk
File_Write("log.txt", "hello")
~~~

#### File_Delete

作用：删除指定文件；文件不存在时不执行删除。

参数：

- path：文件路径。

返回：固定返回 true。

示例：

~~~ahk
File_Delete("temp.txt")
~~~

---

### 10. GUI/GuiTemplate.ahk

#### GUI_Create

作用：创建基础透明置顶状态窗口，并同时创建状态文本控件。

参数：

- title：窗口标题。
- width：窗口宽度。
- height：窗口高度。
- text：初始显示文字。

返回：

~~~ahk
{
    gui: gui对象,
    status: 文本控件
}
~~~

示例：

~~~ahk
guiState := GUI_Create("测试", 300, 35, "● 待机")
~~~

#### GUI_SetText

作用：修改 GUI_Create() 返回对象中的状态文字。

参数：

- gui_state：GUI_Create() 返回对象。
- text：新的显示文字。

返回：固定返回 true。

示例：

~~~ahk
GUI_SetText(guiState, "● 运行中")
~~~

### 11. Input/InputControl.ahk

#### Input_RegisterKey

作用：把按键加入统一释放数组。

参数：

- keys：按键数组。
- key：要注册的按键名称。

返回：更新后的 keys 数组。

示例：

~~~ahk
keys := []
keys := Input_RegisterKey(keys, "w")
keys := Input_RegisterKey(keys, "q")
~~~

#### Input_KeyDown

作用：通过 SendEvent 按下指定按键。

参数：

- key：按键名称。

返回：固定返回 true。

示例：

~~~ahk
Input_KeyDown("w")
~~~

#### Input_KeyUp

作用：通过 SendEvent 释放指定按键。

参数：

- key：按键名称。

返回：固定返回 true。

示例：

~~~ahk
Input_KeyUp("w")
~~~

#### Input_ReleaseKeys

作用：按顺序释放传入数组中的所有按键。

参数：

- keys：按键名称数组。

返回：固定返回 true。

依赖：内部调用 Input_KeyUp()。

示例：

~~~ahk
Input_ReleaseKeys(["w", "q", "f"])
~~~

---

### 12. Manager/ManagerControl.ahk

#### Manager_LoadScripts

作用：读取指定目录下所有 .ahk 文件，并生成脚本对象数组。

参数：

- folder：脚本目录。

返回：数组元素结构为：

~~~ahk
{
    name: 文件名,
    path: 完整路径
}
~~~

示例：

~~~ahk
scripts := Manager_LoadScripts(A_ScriptDir "\Business\SHIFT")
~~~

说明：函数只负责读取，不负责排序。

#### Manager_GetScriptName

作用：获取脚本对象中的显示名称。

参数：

- script：Manager_LoadScripts() 返回的脚本对象。

返回：script.name。

示例：

~~~ahk
name := Manager_GetScriptName(scripts[1])
~~~

---

### 13. Manager/ManagerScriptControl.ahk

#### ManagerScript_Start

作用：启动指定脚本。

参数：

- script_path：脚本完整路径。

返回：无显式返回值。

示例：

~~~ahk
ManagerScript_Start(scriptPath)
~~~

#### ManagerScript_ReadHwnd

作用：读取脚本对应的 hwnd 状态文件。

参数：

- script_path：脚本路径。

文件规则：

~~~text
MAIN.ahk
↓
MAIN.ahk.txt
~~~

返回：

- 文件不存在：0。
- 文件存在：转换后的整数 hwnd。

示例：

~~~ahk
hwnd := ManagerScript_ReadHwnd(scriptPath)
~~~

#### ManagerScript_IsRunning

作用：通过 hwnd 判断脚本窗口是否存在。

参数：

- hwnd：窗口句柄。

返回：窗口存在返回 true，否则返回 false。

示例：

~~~ahk
if ManagerScript_IsRunning(hwnd)
    MsgBox("运行中")
~~~

#### ManagerScript_SendExit

作用：向指定脚本窗口发送统一的 0xB001 退出消息。

参数：

- hwnd：目标窗口句柄。

返回：无显式返回值。

执行条件：只有 ManagerScript_IsRunning(hwnd) 成立时才发送消息。

示例：

~~~ahk
ManagerScript_SendExit(hwnd)
~~~

### 14. SubScript/SubScriptTemplate.ahk

#### SubScript_RegisterHwnd

作用：把当前子脚本 GUI 的 hwnd 写入本脚本目录中的句柄文件。

参数：

- gui_hwnd：GUI 窗口句柄。

文件规则：

~~~text
A_ScriptDir / A_ScriptName.txt
~~~

例如：

~~~text
MAIN.ahk
→
MAIN.ahk.txt
~~~

返回：句柄文件完整路径。

示例：

~~~ahk
hwndFile := SubScript_RegisterHwnd(myGui.Hwnd)
~~~

#### SubScript_InitExit

作用：同时注册 GL 退出消息处理和脚本退出清理。

参数：

- pressed_keys：已注册的按键数组。
- hwnd_file：当前脚本句柄文件路径。

返回：固定返回 true。

执行内容：

- 注册 0xB001 消息。
- 注册 OnExit 清理。
- 绑定按键数组和 hwnd 文件路径。

示例：

~~~ahk
pressedKeys := []
hwndFile := SubScript_RegisterHwnd(myGui.Hwnd)
SubScript_InitExit(pressedKeys, hwndFile)
~~~

#### SubScript_Exit

作用：接收 GL 的 0xB001 退出请求，先清理，再结束脚本。

参数：

- pressed_keys：已注册的按键数组。
- hwnd_file：句柄文件路径。
- *：消息回调剩余参数。

返回：无显式返回值；最终执行 ExitApp。

#### SubScript_Cleanup

作用：清理子脚本按键状态和 hwnd 文件。

参数：

- pressed_keys：需要释放的按键数组。
- hwnd_file：句柄文件路径。

返回：固定返回 true。

依赖：内部调用 Input_ReleaseKeys()。

示例：

~~~ahk
SubScript_Cleanup(pressedKeys, hwndFile)
~~~

### 15. Window/WindowControl.ahk

#### Window_GetActive

作用：获取当前活动窗口 hwnd。

参数：

返回：当前活动窗口 hwnd。

作用：把指定窗口设置为 AlwaysOnTop。

参数：

- hwnd：目标窗口句柄。

返回：固定返回 true。

示例：

~~~ahk
Window_SetTop(hwnd)
~~~

#### Window_SendMessage

作用：向指定 hwnd 同步发送消息。

参数：

- hwnd：目标窗口句柄。
- msg：消息编号。

返回：SendMessage() 的结果。

示例：

~~~ahk

~~~

## 三、公共库 Include 示例

~~~ahk
#Include ../../Lib/Common/GUI.ahk
#Include ../../Lib/Common/Message.ahk
#Include ../../Lib/Action/Keyboard.ahk
#Include ../../Lib/Action/Timer.ahk
~~~

~~~ahk

#Include ../../Lib/SubScript/SubScriptTemplate.ahk
~~~

使用模板库前，要保证其依赖函数已经通过 Include 加载。

## 四、函数调用原则

1. 公共库负责通用、可复用的基础操作。
2. 业务逻辑放在 Task_Process.ahk。
3. 具体按键、窗口动作放在 Task_Action.ahk。
4. MAIN.ahk 只负责 Include、初始化、热键入口和启动。
5. 业务状态由业务脚本自己管理。
6. 公共函数通过参数和返回值传递数据。
