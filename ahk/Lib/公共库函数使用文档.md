# 公共库函数使用文档

本文件只记录当前仓库实际存在的公共库函数/类。公共库命名统一采用：

```text
Common_具体脚本名称_具体功能
```

“具体脚本名称”必须对应公共库源码所属的真实具体脚本名称，作为完整语义单元保留，不得拆分，也不得用调用方业务名称代替。

## Common/GUI.ahk

### Common_GUI_Create
`Common_GUI_Create(title := "", width := 300, height := 35, x := unset, y := unset)`

创建项目统一样式的置顶黑底透明 GUI，并返回 `{gui, controls}` 状态对象。使用 AlwaysOnTop、Microsoft YaHei、s9、220 透明度和 NoActivate。

### Common_GUI_UpdateList
`Common_GUI_UpdateList(state, scripts, currentIndex)`

更新管理器脚本列表，当前项显示红色，其余显示白色。

## Common/Message.ahk

### Common_Message_Exit
保存 GL 管理器与子脚本通信使用的消息编号和退出原因：
- `ExitMessage`：`0xB001`
- `ExitReasonSwitch`：`1`
- `ExitReasonManager`：`2`

### Common_Message_SendExit
`Common_Message_SendExit(hwnd, reason := Common_Message_Exit.ExitReasonSwitch)`

向指定 hwnd 异步发送统一退出消息。

## Common/Log.ahk

### Common_Log_Error
`Common_Log_Error(reason, detail := "")`

覆盖式记录当前脚本最近一次错误或异常退出信息到 `A_ScriptDir\\Error.log`。

## Action/Keyboard.ahk

### Common_Keyboard_Common_Keyboard_KeyDown
`Common_Keyboard_Common_Keyboard_KeyDown(key)`

使用 `Send` 按下指定按键。

### Common_Keyboard_Common_Keyboard_KeyUp
`Common_Keyboard_Common_Keyboard_KeyUp(key)`

使用 `Send` 释放指定按键。

## Action/Timer.ahk

### Common_Common_Timer_Start
`Common_Common_Timer_Start(callback, interval)`

启动或重新设置指定回调的定时器。

### Common_Common_Timer_Stop
`Common_Common_Timer_Stop(callback)`

停止指定回调对应的定时器。

## Action/Window.ahk

### Common_Window_Activate
`Common_Window_Activate(hwnd)`

激活指定窗口。

### Common_Window_Exists
`Common_Window_Exists(hwnd)`

检查指定 hwnd 对应的窗口是否存在。

## File/FileControl.ahk

### Common_Common_File_Exists
`Common_Common_File_Exists(path)`

检查文件是否存在。

### Common_Common_File_Read
`Common_Common_File_Read(path)`

读取文本文件内容。

### Common_Common_File_Write
`Common_Common_File_Write(path, data)`

覆盖写入文本数据。

### Common_Common_File_Delete
`Common_Common_File_Delete(path)`

删除指定文件；文件不存在时直接返回。

## Input/InputControl.ahk

### Common_InputControl_CreateGuard
`Common_InputControl_CreateGuard(controlKeys := [])`

创建输入干扰检测状态并登记控制键。

### Common_InputControl_StartGuard
`Common_InputControl_StartGuard(state, interferenceCallback, resumeCallback)`

建立物理按键基线并开始检测新的物理输入。

### Common_InputControl_StopGuard
`Common_InputControl_StopGuard(state)`

停止输入干扰检测并清空检测状态。

### Common_InputControl_CheckGuard
`Common_InputControl_CheckGuard(state, interferenceCallback, resumeCallback)`

执行一次输入保护检测，发现新增输入时触发干扰回调，干扰键全部释放后触发恢复回调。

### Common_InputControl_CapturePhysicalKeys
`Common_InputControl_CapturePhysicalKeys()`

获取当前处于物理按下状态的虚拟键。

### Common_InputControl_FindNewPhysicalKeys
`Common_InputControl_FindNewPhysicalKeys(baseline, currentKeys, ignoredKeys)`

找出启动基线之后新增的物理按键，并忽略控制键。

### Common_InputControl_RemoveReleasedInterferenceKeys
`Common_InputControl_RemoveReleasedInterferenceKeys(interferenceKeys, currentKeys)`

删除已经物理释放的干扰键。

### Common_InputControl_IsImeOpen
`Common_InputControl_IsImeOpen()`

判断当前活动窗口是否处于开启输入法状态。

### Common_InputControl_Common_Keyboard_KeyDown
`Common_InputControl_Common_Keyboard_KeyDown(key)`

使用 `SendEvent` 按下指定按键。

### Common_InputControl_Common_Keyboard_KeyUp
`Common_InputControl_Common_Keyboard_KeyUp(key)`

使用 `SendEvent` 释放指定按键。

### Common_InputControl_ReleaseKeys
`Common_InputControl_ReleaseKeys(keys)`

按顺序释放传入数组中的所有按键。
