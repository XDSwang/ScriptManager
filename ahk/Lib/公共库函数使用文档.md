# 公共库函数使用文档

本文件只记录当前仓库实际存在的公共库函数。源码中的公共函数只保留一行“作用 + 参数”注释；这里记录具体函数行为、返回值以及必要的副作用。

## Common/GUI.ahk

### GLGui.Create

**调用：**
`GLGui.Create(title := "", width := 300, height := 35, x := unset, y := unset)`

**作用：** 创建项目统一样式的置顶黑底透明 GUI，并返回 GUI 状态对象。

**参数：**
- `title`：窗口标题。
- `width`：窗口宽度。
- `height`：窗口高度。
- `x`：可选横坐标；与 `y` 同时提供时使用指定位置。
- `y`：可选纵坐标；与 `x` 同时提供时使用指定位置。

**返回：**
```ahk
{
    gui: GUI 对象,
    controls: []
}
```

**行为：** 使用 AlwaysOnTop、黑色背景、Microsoft YaHei、s9、白色默认字体和 220 透明度。

### GLGui.UpdateList

**调用：**
`GLGui.UpdateList(state, scripts, currentIndex)`

**作用：** 更新管理器 GUI 中的脚本名称列表，并把当前脚本设为红色，其余设为白色。

**参数：**
- `state`：`GLGui.Create()` 返回的 GUI 状态对象。
- `scripts`：脚本对象数组；每项至少包含 `name`。
- `currentIndex`：当前脚本在数组中的索引。

**返回：**
- 状态对象有效：返回传入的 `state`。
- 状态对象无效：返回 `0`。

**副作用：** 创建、移动、更新或隐藏列表文本控件。

## Common/Message.ahk

### GLMessage

**作用：** 保存 GL 管理器与子脚本通信所使用的消息编号和退出原因。

**常量：**
- `ExitMessage`：`0xB001`。
- `ExitReasonSwitch`：`1`，表示 GL 切换脚本。
- `ExitReasonManager`：`2`，表示 GL 管理器 F8 退出。

### SendExitMessage

**调用：**
`SendExitMessage(hwnd, reason := GLMessage.ExitReasonSwitch)`

**作用：** 向指定 hwnd 发送统一的 GL 退出消息。

**参数：**
- `hwnd`：目标窗口句柄。
- `reason`：退出原因，默认使用切换脚本原因。

**返回：** 固定返回 `true`。

**副作用：** 通过 `PostMessage` 发送 `0xB001` 异步消息。

## Common/Log.ahk

### GL_LogError

**调用：**
`GL_LogError(reason, detail := "")`

**作用：** 记录当前脚本最近一次错误或异常退出信息。

**参数：**
- `reason`：错误或退出原因。
- `detail`：附加说明，可省略。

**返回：** 固定返回 `true`。

**行为：** 日志写入当前脚本目录的 `Error.log`；写入前删除旧文件，因此始终覆盖为最近一次记录。

## Input/InputControl.ahk

### Input_CreateGuard

**调用：**
`Input_CreateGuard(controlKeys := [])`

**作用：** 创建输入干扰检测状态，并登记本脚本用于启动、暂停、退出等控制功能的按键。登记的控制键不会被输入干扰保护判定为新的用户输入。

**参数：**
- `controlKeys`：控制键名称数组，例如 `["F6", "F7"]`；可以加入本脚本实际使用的其他启动、暂停或退出控制键。

**返回：**
```ahk
{
    monitoring: false,
    paused: false,
    baseline: Map(),
    ignoredKeys: Map(),
    timer: 0
}
```

**重要提醒：**
- 控制键会被输入保护主动忽略，因此不要把同时承担游戏技能、业务输入或其他需要被检测的按键作为控制键。
- 如果以后把启动、暂停或退出热键改成其他按键，应同步修改本脚本 MAIN 中传给 `Input_CreateGuard()` 的 `controlKeys`。
- 控制键按住不松也不会被输入保护强制抬起；控制键的按下/抬起完全由用户和热键机制处理。

### Input_StartGuard

**调用：**
`Input_StartGuard(state, interferenceCallback, resumeCallback)`

**作用：** 记录当前物理按键作为基线，并开始检测新的物理输入。

**参数：**
- `state`：输入检测状态对象。
- `interferenceCallback`：检测到新增物理输入时执行的回调。
- `resumeCallback`：新增输入消失后执行的恢复回调。

**返回：** 固定返回 `true`。

**行为：** 启动前会先停止已有检测；监测定时器间隔为 20 ms。

### Input_StopGuard

**调用：**
`Input_StopGuard(state)`

**作用：** 停止输入干扰检测并清空检测状态。

**参数：**
- `state`：输入检测状态对象。

**返回：** 固定返回 `true`。

### Input_CheckGuard

**调用：**
`Input_CheckGuard(state, interferenceCallback, resumeCallback)`

**作用：** 根据当前状态检测新增物理输入，并在需要时触发暂停或恢复回调。

**参数：**
- `state`：输入检测状态对象。
- `interferenceCallback`：发生新增物理输入时执行的回调。
- `resumeCallback`：干扰解除后执行的恢复回调。

**返回：**
- `true`：本次检查发生了暂停或恢复状态转换。
- `false`：没有状态转换，或当前没有进行监测。

### Input_CapturePhysicalKeys

**调用：**
`Input_CapturePhysicalKeys()`

**作用：** 获取当前处于物理按下状态的虚拟键。

**参数：** 无。

**返回：** `Map`；键为 `vk01` 到 `vkFE` 的虚拟键名称，值为 `true`。

### Input_FindNewPhysicalInput

**调用：**
`Input_FindNewPhysicalInput(baseline, ignoredKeys := unset)`

**作用：** 对比启动基线和当前物理按键，判断是否出现新增物理输入，并忽略调用方声明的控制键。

**参数：**
- `baseline`：启动时建立的物理按键基线，会被函数同步更新。
- `ignoredKeys`：需要忽略的虚拟键名称 `Map`；通常由 `Input_CreateGuard()` 创建并保存在状态对象中，可省略。

**返回：**
- 存在新增物理输入：`true`。
- 不存在新增物理输入：`false`。

**副作用：** 已经物理释放的基线按键会从 `baseline` 中移除；因此后续再次按下会被视为新的输入。

**IME：** 当前活动窗口处于开启输入法状态时直接返回 `false`。

### Input_IsImeOpen

**调用：**
`Input_IsImeOpen()`

**作用：** 判断当前活动窗口是否处于开启输入法状态。

**参数：** 无。

**返回：**
- 输入法开启：`true`。
- 输入法未开启、没有活动窗口或无法取得 IME 上下文：`false`。

**参数：**
- `key`：AHK 按键名称。

**作用：** 使用 `SendEvent` 释放指定按键。

**参数：**
- `key`：AHK 按键名称。

**返回：** 固定返回 `true`。

### Input_ReleaseKeys

**调用：**
`Input_ReleaseKeys(keys)`

**作用：** 按顺序释放传入数组中的所有按键。

**参数：**
- `keys`：需要释放的 AHK 按键名称数组。

**返回：** 固定返回 `true`。

**依赖：** 内部逐项调用 `Input_KeyUp()`。
